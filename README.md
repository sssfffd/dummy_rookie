# IO Log Scope

엑셀 로그 파일을 열면 IO 채널별 파형을 그려 주는 단일 파일 웹 앱입니다.
설치·빌드 과정 없이 `index.html`을 브라우저에서 열면 바로 동작합니다.

## 입력 데이터 형식

기본 배치는 **행 = IO 채널**입니다.

| | B | C | D | … |
|---|---|---|---|---|
| **Time [s]** | 0.00 | 0.01 | 0.02 | … |
| **DI_00_CYCLE_START** | 0 | 0 | 1 | … |
| **AI_TEMP_BARREL1** | 182.4 | 182.6 | 182.5 | … |
| **SEQ_STATE** | IDLE | IDLE | RUN | … |

- **첫 행** = 시간축. 숫자(초/ms), `HH:MM:SS.mmm` 문자열, 엑셀 날짜/시간 셀을 인식합니다.
  해석이 안 되거나 값이 증가하지 않으면 샘플 번호(0…N)를 시간축으로 씁니다.
  `Time [s]`처럼 첫 셀에 단위를 적어 두면 축 라벨에 반영됩니다.
- **각 행의 첫 열** = IO 이름. 이름이 비어 있으면 `IO_001` 형태로 자동 부여합니다.
- 시간축이 세로로 내려가는 파일이면 상단의 **배치: 열=IO** 로 전환하면 됩니다.
- `.xlsx`, `.xls`, `.xlsm`, `.csv`, `.tsv` 를 읽습니다. 시트가 여러 개면 우측 상단에서 고릅니다.

### 채널 타입 자동 판별

| 타입 | 판별 기준 | 표현 |
|---|---|---|
| `DIG` | 값이 0/1, TRUE/FALSE, ON/OFF, HIGH/LOW 뿐 | 스텝 파형 + 하이 구간 채움 |
| `ANA` | 값이 모두 숫자 | 라인 + 면 채움, 레인별 자동 스케일 |
| `STATE` | 문자열 상태값 | 상태 리본 (구간별 색 + 라벨) |

빈 셀은 값이 아니라 **끊김**으로 처리해 선을 잇지 않습니다.

## 화면 구성

- **좌측 채널 목록** — 이름 검색, `ALL / DIG / ANA / STATE` 필터, 개별 체크박스, 전체 선택·해제.
  채널이 40개를 넘으면 앞 40개만 켠 상태로 시작합니다.
- **레인 보기** (기본) — 로직 애널라이저처럼 채널마다 한 줄. 왼쪽에 IO 이름, 오른쪽 거터에
  커서 위치의 값(아날로그는 최소–최대 범위까지) 을 표시합니다. 채널 수만큼 세로 스크롤됩니다.
- **겹쳐보기** — 최대 8개 채널을 한 축에 겹쳐 그립니다. 범례와 툴팁이 붙고,
  스케일이 크게 다른 채널은 `0–1 정규화` 로 맞춰 볼 수 있습니다.
- **커서 A/B** — 두 시점을 찍어 Δt 를 읽습니다. 하단 판독 표에 채널별
  A 값, B 값, Δ(아날로그는 차이, 디지털은 구간 내 에지 수), 최소·최대가 나옵니다.

## 조작

| 동작 | 조작 |
|---|---|
| 커서 A 놓기 | 플롯 클릭 |
| 커서 B 놓기 | Shift + 클릭 |
| 시간축 이동 | 드래그 (또는 ← →) |
| 시간축 확대/축소 | Ctrl(⌘/Alt) + 휠 (또는 `+` `-`) · 겹쳐보기에서는 휠만으로 |
| 전체 보기 | 더블클릭 · `0` · `전체 보기` 버튼 |
| 파일 열기 | 버튼 클릭 또는 창에 드래그 앤 드롭 |

레인 보기에서 그냥 휠을 굴리면 채널 목록이 세로로 스크롤됩니다.

## 구현 메모

- 의존성은 엑셀 파싱용 [SheetJS](https://sheetjs.com) 하나뿐이며 CDN에서 불러옵니다.
  파일은 브라우저 안에서만 읽고 어디로도 전송하지 않습니다.
- 파형은 `<canvas>` 에 직접 그립니다. 화면 밖 레인은 그리지 않고(가상 스크롤),
  샘플이 픽셀보다 촘촘하면 픽셀 열마다 최소·최대만 뽑아 그립니다.
- 처음 열면 예시 로그(15채널 × 420샘플)가 올라와 있어 파일 없이도 동작을 볼 수 있습니다.
- 라이트/다크 테마를 모두 지원합니다.
