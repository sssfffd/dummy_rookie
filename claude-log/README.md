# Claude 대화 로그

폰에서 프롬프트를 넣고 PC에서 git 으로 읽기 위한 폴더입니다.
채팅 화면에만 남는 Claude 의 답변을 여기에 turn 단위로 저장합니다.

각 파일은 그 turn 의 **요청 원문**, **답변 전문**, 그리고 그 turn 에서 나온
**커밋과 바뀐 파일**을 함께 담습니다. 코드 변경과 그 이유를 한자리에서 볼 수 있게
하려는 것이고, 그래서 `git log` 만으로는 안 보이는 판단 근거가 여기 남습니다.

## 규칙

- 파일 이름은 `NN-슬러그.md`, 번호는 turn 순서대로 올라갑니다.
- 답변은 채팅에 나간 그대로 옮깁니다. 나중에 다듬거나 고치지 않습니다.
  잘못된 판단도 그대로 남아야 왜 그렇게 갔는지 추적이 됩니다.
- 이어지는 turn 마다 파일을 하나씩 더하고, 위 목록에 줄을 추가합니다.
