# 16 · 마우스를 움직이면 검색창이 깜빡이던 문제

- **날짜** 2026-09-04
- **커밋** 이 커밋
- **바뀐 파일** `src/app/app.cpp`, `src/app/app.h`, `src/app/CMakeLists.txt`, `README.md`

## 요청

> 그리고 그래프 위에 마우스 올려두고 마우스 쓱 옮기면 io값들 위에 뜨는 거 바뀌잖아? 그거 바뀌면서 io 이름 검색창도 업데이트 되는건지 계속 깜빡거리는데 이거 해결해줘

## 답변

검색창이 업데이트되는 게 아니라, **매 프레임 지워졌다 다시 그려지고 있었습니다.**

### 원인

검색 상자만 **Win32 자식 컨트롤(EDIT)** 이었습니다. 나머지 화면은 전부 Direct2D 로
직접 그리는데, 이 둘을 섞으면 다음 두 가지가 겹칩니다.

1. `Render()` 가 매 프레임 `MoveWindow(search_, ..., TRUE)` 를 불렀습니다. 위치가
   바뀌지 않아도 마지막 인자가 `TRUE` 라 그때마다 컨트롤을 **강제로 다시 그립니다.**
2. Direct2D 의 `HwndRenderTarget` 은 창 전체를 한 장으로 올립니다. 자식 컨트롤이
   있는 자리도 예외 없이 덮어쓰고, 그러면 컨트롤이 다시 자기를 그립니다.

마우스를 움직일 때마다 이 왕복이 반복되니 깜빡였습니다. 마우스가 그래프 위에
있을 때 유독 심했던 건, 십자선과 값 표시 때문에 다시 그리는 횟수가 가장 많아서입니다.

### 고친 방법 — 자식 컨트롤을 없앴습니다

`MoveWindow` 호출만 줄이는 것으로는 2번이 남습니다. 검색 상자를 **직접 그리는
방식으로 바꿨습니다.** 이제 창에 자식 윈도우가 하나도 없으므로 이 문제 자체가
사라집니다.

- 상자를 누르면 그 자리에 글자 커서가 놓입니다
- `← →` `Home` `End` `Backspace` `Delete` 동작
- `Esc` 는 글자를 지우고, 비어 있을 때 한 번 더 누르면 검색을 빠져나옵니다
- 검색 중에는 방향키를 글자 커서가 가져갑니다. 그러지 않으면 글자를 지우려다
  그래프가 움직입니다
- 글자 커서는 0.5초 주기로 깜빡이며, **검색 중일 때만** 타이머가 돕니다

**한글 입력도 됩니다.** IME 가 조합을 마친 글자를 `WM_CHAR` 로 보내 주므로 그대로
받고, 조합 중인 글자가 뜨는 위치만 `ImmSetCompositionWindow` 로 글자 커서 옆에
맞춰 줍니다.

### 덤 — 쓸데없는 다시 그리기도 줄였습니다

`WM_MOUSEMOVE` 에서 **데이터가 열려 있기만 하면 무조건** 창 전체를 다시 그리고
있었습니다. 마우스가 왼쪽 목록 위에 있어도, 툴바 위에 있어도 마찬가지였습니다.
이제는 다시 그릴 이유가 있을 때만 그립니다.

- 마우스가 그래프 안에 있을 때 (십자선·값 표시가 바뀜)
- 그래프 밖으로 막 나간 순간 (십자선을 지워야 함)
- 버튼 위에 올라가거나 내려온 순간
- 드래그 중

---

### 검증

mingw 크로스 빌드 Debug/Release 경고 없이 통과, 코어 테스트 155개 통과.

**깜빡임이 실제로 없어졌는지는 확인하지 못했습니다.** 여기는 Linux 라 창을 띄울 수
없습니다. 다만 원인이 자식 컨트롤과 Direct2D 의 조합이었고 자식 컨트롤을 통째로
없앴으므로, 그 경로로는 더 이상 깜빡일 수 없습니다.

새로 만든 입력 상자는 실제로 써 보셔야 합니다.

- 한글 입력이 되는지, 조합 중인 글자가 엉뚱한 곳에 뜨지 않는지
- 글자 커서 위치가 클릭한 자리와 맞는지
- 다른 곳을 눌렀을 때 검색이 잘 빠져나오는지
