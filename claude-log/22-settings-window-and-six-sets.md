## 답변

### 1. 설정 창

오른쪽 위 `설정` 버튼. 화면 위에 **겹쳐** 뜹니다. `Esc` 나 바깥을 누르면 닫힙니다.

창을 하나 더 띄우지 않은 이유는, 자식 창을 쓰면 Direct2D 가 매 프레임 그 위를
덮어써서 계속 깜빡이기 때문입니다 — 검색 상자에서 이미 겪었던 것입니다.

### 2. 판 번호

```
IO Log Scope  1.0.0  (a0b80e7)
빌드          2026-09-08
실행 파일     C:\tools\logscope\logscope.exe
logcore.dll   C:\tools\logscope\logcore.dll
설정 파일     C:\Users\...\AppData\Roaming\LogScope\settings.txt
```

- 판 번호는 `CMakeLists.txt` 의 `project(LogScope VERSION 1.0.0)` **한 곳**에서만
  나옵니다. 손으로 맞출 자리를 만들지 않았습니다
- **커밋 해시**를 같이 둡니다. 같은 `1.0.0` 이라도 어제 빌드와 오늘 빌드를 화면
  하나로 가려낼 수 있습니다. 빌드할 때 git 에서 읽고, git 이 없으면 조용히 넘어갑니다
- **실제로 불러온 파일의 경로**까지 적습니다. `logscope.exe` 와 `logcore.dll` 이 서로
  다른 판으로 섞이는 일이 실제로 생기는데, 화면 한 장으로 그것까지 답이 됩니다

### 3. 로그 세트 여섯 벌

"이전 로그 + 이후 로그" 한 벌이 세트입니다.

- 오른쪽 위 `1 2 3 4 5 6` → 그 세트의 비교 화면으로
- 설정 창에서 세트마다 **이름**과 **기본 폴더 두 개**(이전용·이후용)를 정합니다
- `비우기` 는 그 세트가 기억한 폴더와 파일을 지웁니다. 세트 자체는 남습니다 —
  여섯 벌은 늘 여섯 벌입니다

폴더를 안 정해 두면 예전처럼 Windows 가 기억하는 마지막 폴더가 열립니다.

**세트를 바꾸면 그 세트의 로그를 다시 읽습니다.** 여섯 벌을 한꺼번에 메모리에 올려
두지 않았습니다. 로그 하나가 수백 MB 인 자리에서 열두 개를 들고 있으면 그것만으로
메모리가 바닥나고, 용량 제한을 없애 달라고 하신 것과 정면으로 부딪힙니다.

읽는 중에는 세트를 바꿀 수 없게 막았습니다 — 방금 시작한 읽기가 어느 세트 것인지 알
수 없게 되기 때문입니다. `읽기 취소` 를 누르고 바꾸면 됩니다.

설정은 `%APPDATA%\LogScope\settings.txt` 에 저장됩니다 (그룹 설정과 같은 폴더,
같은 형식). 세트 이름, 폴더 둘, 마지막으로 연 파일 둘, 그리고 마지막으로 보던 세트
번호까지 기억하므로 프로그램을 껐다 켜면 보던 세트로 돌아옵니다.

### 곁들여 고친 것

- 툴바 오른쪽 버튼 묶음은 왼쪽 버튼과 부딪히면 **통째로 아래 컨트롤 줄로 내려갑니다.**
  창을 좁혀도 겹치지 않습니다
- 설정 창 안의 폴더 경로는 버튼 너비에 맞춰 미리 줄입니다. 그리는 쪽이 글자를 잘라
  주지 않아서, 여기서 하지 않으면 버튼 밖으로 넘칩니다

- 세트 이름에 한글을 넣을 때 IME 가 제자리에 뜨는지
