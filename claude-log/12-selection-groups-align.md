## 답변

### 겹침 — 원인이 하나였고, "전체 선택"이 없던 이유도 같았습니다

레일 머리 부분의 각 요소를 따로따로 계산하고 있었습니다.

```
목록 시작   = rail.top + 84
필터 칩     = 58 ~ 78
개수 표시   = 64 ~ 82     <- 칩과 겹침
전체 선택   = 84 ~ 102    <- 목록 영역과 겹침
```

**"전체 선택 / 전체 해제" 는 원래 있었습니다.** 다만 버튼을 그리는 조건이
`bottom <= 목록 시작` 이었는데 `102 <= 84` 가 거짓이라 **한 번도 그려지지
않았습니다.** 없다고 느끼신 게 맞습니다.

머리 부분을 밴드로 쌓아 한 함수(`RailHeaderHeight`)에서 계산하도록 바꿨습니다.
비교 중일 때는 `달라진 것만` 칩이 줄을 바꿔 내려가고, 개수 표시는 목록 바로 위
오른쪽 끝으로 옮겼습니다.

### 선택 방식

처음에 **아무것도 선택되지 않은 상태**로 시작합니다. 200채널을 다 그려 놓고
지우는 것보다 볼 것을 골라 담는 쪽이 빠릅니다.

| 조작 | 결과 |
|---|---|
| 이름 클릭 | 그 하나만 선택 (나머지 해제) |
| **Ctrl + 클릭** | 그 하나만 켜고 끄기 |
| **Shift + 클릭** | 직전 채널부터 여기까지 한 번에 |
| 체크 상자 클릭 | 그 하나만 켜고 끄기 |

`전체 선택` 은 **지금 목록에 보이는 것** 만 대상으로 합니다. 필터를 걸어 두고
전체 선택을 누르면 걸린 것만 켜집니다.

### 10개 단위 그룹

채널을 10개씩 묶고, 그룹 머리에 삼각형(펼침)과 체크 상자(그룹 전체 선택), 그리고
`3/10` 처럼 선택 개수를 답니다. 일부만 켜져 있으면 체크 상자에 가로줄로 표시합니다.
`펴기` / `접기` 버튼으로 전부 여닫습니다.

목록을 `RailRow` 배열 하나로 다시 만들어서 그룹 머리·채널·신규 채널이 같은 방식으로
스크롤되고 클릭 판정을 받습니다.

### 두 로그 시간 맞추기

| 버튼 | 하는 일 |
|---|---|
| **◀ ▶** | 이후 로그를 한 표본 간격씩 민다 |
| **자동 정렬** | 값이 가장 잘 맞는 위치를 찾는다 |
| **정렬 해제** | 보정 0 으로 |

자동 정렬은 이후 로그를 밀어 보며 차이의 합이 최소가 되는 지점을 찾습니다. 전
구간의 ±40% 를 80칸으로 성기게 훑은 뒤, 찾은 곳 주변을 표본 간격 단위로 다시
봅니다. 채널마다 값 크기가 다르므로 각자의 범위로 나눠 정규화해서 더합니다.
겹치는 구간이 8점도 안 되면 억지로 맞춘 것으로 보고 버립니다.

### 겹쳐서 구분이 안 되던 문제

값이 같은 구간에서는 두 선이 **정확히 포개져** 하나로 보입니다. 두 가지를 넣었습니다.

1. **이후 로그를 점선으로** 그립니다 (`ID2D1StrokeStyle` 의 대시 패턴). 포개져도
   점선이 비쳐 두 개임이 보입니다.
2. **벌려 그리기** 토글 — 이후 선을 레인 높이의 10%만큼 띄워 그립니다. 값을 바꾸는
   게 아니라 그리는 위치만 옮기는 것이고, 버튼으로 켜고 끄니 오해할 여지도 없습니다.

### IO 존재 차이

이전에는 이후 로그에 짝이 없는 채널만 `없음` 으로 표시했습니다. 반대쪽 —
**이후 로그에만 새로 생긴 채널** — 은 아예 보이지 않았습니다.

- 이전에만 있음 → 목록에 **`삭제`** (주황)
- 이후에만 있음 → 목록 맨 아래 **"이후 로그에만 있음 (n)"** 칸에 모아서, 각 줄에 **`신규`**
- 상태 표시줄에 `이전에만 있음 n · 이후에만 있음 m` 이 늘 표시
- `달라진 것만` 필터가 값이 바뀐 채널과 **사라진 채널**을 함께 보여 줍니다

신규 채널은 이전 로그에 짝이 없어 같은 시간 격자에 그릴 수 없으므로 이름만
보여 줍니다. 그리기까지 필요하시면 말씀해 주세요.
