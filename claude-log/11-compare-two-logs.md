## 요청

> 그리고 같은 양식의 로그 2개를 넣어서 각 io들의 차이도 볼려고함 이전로그 이후로그 2개를 넣을 수도 있게 만들어줘

## 답변

만들었습니다. 두 로그를 견주려면 결국 두 가지를 풀어야 합니다 — **어느 채널이 어느
채널과 짝인가**, 그리고 **표본 시각이 다른 두 로그를 어떻게 맞추는가**.

### 넣는 방법 세 가지

- 툴바의 **이전 로그 열기** → **이후 로그 열기**
- 두 파일을 **한 번에 창에 끌어다 놓기** (첫 번째가 이전, 두 번째가 이후)
- 명령줄: `logscope.exe before.xlsx after.xlsx`

### 채널 맞추기

이름으로 맞춥니다. 정확히 같은 이름을 먼저 보고, 없으면 앞뒤 공백과 대소문자를
무시하고 다시 찾습니다. 같은 장비에서 뽑은 로그라도 그 정도 차이는 흔합니다.
짝을 못 찾으면 목록에 `없음` 으로 표시합니다.

### 시간축 맞추기

**두 로그의 시각이 같은 기준일 거라고 가정하지 않습니다.** 절대 시각으로 찍힌
로그라면 측정한 날짜부터 다릅니다. 그래서 각자의 시작점을 0 으로 놓고 *시작 이후
경과 시간* 으로 맞춥니다. 표본 간격이 서로 달라도 됩니다 — 이후 로그를 이전 로그의
시간 격자 위로 다시 읽어 옵니다.

- **아날로그** — 앞뒤 샘플을 선형 보간
- **디지털·상태** — 직전 샘플 값을 유지 (계단). 보간하면 0 과 1 사이에 없던
  0.5 가 생깁니다.
- 기록 구간 밖은 NaN 입니다. 없는 데이터를 지어내지 않습니다.

여기서 **버그를 하나 잡았습니다.** 처음 구현은 `lower_bound` 를 써서, `t` 가 샘플
시각과 정확히 같을 때 *직전* 값을 돌려줬습니다. 즉 신호가 바뀌는 바로 그 순간에
바뀌기 전 값을 읽었습니다. 테스트가 잡아냈고 `upper_bound - 1` 로 고쳤습니다.

### 어느 IO 가 바뀌었는가 — 가장 먼저 알고 싶은 것

채널 목록 오른쪽 표시가 타입 대신 비교 결과로 바뀝니다.

| 표시 | 뜻 |
|---|---|
| `동일` | 값이 같음 |
| `Δ37` | 값이 다른 샘플이 37개 |
| `없음` | 이후 로그에 같은 이름의 채널이 없음 |

**`달라진 것만`** 필터를 누르면 바뀐 IO 만 남습니다. 200채널 로그 두 개를 견줄 때
이게 실제로 쓰는 기능입니다.

두 가지를 신경 썼습니다.

- 아날로그는 값 범위의 **1/1000** 을 넘게 벌어졌을 때만 다르다고 셉니다. 그러지
  않으면 반올림 차이까지 전부 잡혀서 "전부 달라짐" 이 됩니다.
- 상태 채널은 상태 번호가 로그마다 다르게 매겨지므로 **이름으로** 비교합니다.
  번호로 비교하면 같은 `RUN` 이 다른 값으로 잡힙니다.

### 그리는 방식 두 가지

- **이전+이후** — 같은 눈금에 겹칩니다. 레인에서는 파랑이 이전, 주황이 이후.
  겹쳐보기에서는 색이 채널을 뜻하고 진한 선이 이전, 옅은 선이 이후입니다.
- **차이 Δ** — 이후에서 이전을 뺀 값만 그립니다. 0 선을 함께 그어서 어느 쪽으로
  벌어졌는지 보입니다. 상태 채널은 다르면 1, 같으면 0.

레인 오른쪽 거터에는 이전 값 / 이후 값 / Δ 가 위아래로 쌓입니다.

### 새 ABI

```c
int32_t lc_find_channel(const LcDataset*, const wchar_t* name);
double  lc_sample_at(const LcDataset*, uint32_t ch, double t);
```

리샘플링과 이름 찾기를 `dataset.cpp` 에 두고 ABI 는 위임만 하게 했습니다. 덕분에
Windows 없이도 테스트할 수 있습니다.

### 검증

테스트 **129개 → 155개**, AddressSanitizer + UBSan 아래 전부 통과. 새로 넣은 것:

- 이름 찾기 (정확 일치 / 공백·대소문자 무시 / 못 찾음)
- 임의 시각 값 읽기 — 아날로그 보간, 디지털 계단, 구간 밖 NaN
- **표본 간격도 시간 원점도 다른 두 로그** 를 맞춰 차이를 세는 전체 흐름

mingw 크로스 빌드 Debug/Release 모두 경고 없이 통과.

**덤으로 잡은 것**: `CommandLineToArgvW` 는 빈 문자열을 받으면 인자 대신 실행 파일
경로를 돌려줍니다. 그대로 뒀으면 인자 없이 실행할 때 **자기 자신을 로그로 열려고**
했을 겁니다.
