### 2. ＋ 는 "고른 IO 담기" 였습니다 — 이름을 붙였습니다

먼저 답: 그룹명 옆의 두 개는 **`×` 가 그룹 삭제**, **`＋` 가 "지금 고른 IO 들을 이
그룹으로 옮기기"** 였습니다 (`－` 가 아니라 `×` 였습니다).

물어보셨다는 것 자체가 **기호만으로는 알 수 없다**는 뜻이라, 글자로 바꿨습니다.

```
전:  [▸] [☐] 온도            ＋  ×   3/12
후:  [▸] [☐] 온도        담기  삭제   3/12
```

예전에 "ui위에 화살표 버튼이 뭔지 모르겠음" 하셨을 때 화살표에 이름을 붙였던 것과
같은 이유입니다. 이름 칸은 그만큼 좁아졌지만, 무엇을 누르는지 모르는 것보다 낫습니다.

**담기** 는 검색과 같이 쓸 때 제일 쓸모가 있습니다 — 검색창에 `AI_TEMP` → `전체 선택`
→ 원하는 그룹의 `담기`.

### 3. 판 번호 0.00, 고칠 때마다 0.01

- 이번 커밋이 **0.00** 입니다 (시작점). 다음 수정부터 0.01, 0.02 … 로 올립니다
- 판 번호는 `CMakeLists.txt` 의 `LOGSCOPE_VERSION` **한 곳**에만 있습니다.
  화면도 `version.h` 도 전부 이 값을 그대로 씁니다
- 예전에 있던 `project(... VERSION 1.0.0)` 은 없앴습니다. 두 곳에 적히면 언젠가
  어긋납니다

```cmake
# 판 번호는 여기 한 곳에서만 나온다. **파일을 고칠 때마다 0.01 씩 올린다.**
set(LOGSCOPE_VERSION "0.00")
```

커밋 해시는 그대로 같이 나옵니다. 같은 0.01 이라도 빌드를 두 번 드렸다면 해시로
가려집니다.
